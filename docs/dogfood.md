# Dogfooding

plumb-line is held to its own principles. At each release the
`plumb-line-audit` methodology, the same two-pass audit it tells you to run,
is applied to plumb-line's own first-party source, and what it found and what
was done about each finding is recorded. (An auditor that sniffs out code
smells should pass its own smell test.)

Each self-audit is recorded in its own file in
[`records/dogfood/`](records/dogfood/). The records were moved here,
verbatim, from this file's earlier single-page form (#570); only their
headings and relative links changed. The release validation runs are in
[`validation-results.md`](validation-results.md).
