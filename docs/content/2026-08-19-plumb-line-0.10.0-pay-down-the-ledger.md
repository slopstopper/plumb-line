# plumb-line 0.10.0 — pay down the ledger

plumb-line 0.10.0 is out on npm, PyPI, and the Claude Code marketplace. No
headline feature this time. The release closes twelve tracked issues, most of
them the project's own audit findings filed against itself, and that is the
point of it.

Three of the fixes change published behavior, all in the same direction.
An HTTP `Age` header the adapter can see but cannot parse used to read as
absent, so the response classified as fresh with full confidence; it now
degrades to `medium`, and ADR-0014 records the precedent for every future
adapter: unknown never resolves toward more trust. A fractional
`provenanceVersion` used to read as "predates version 2", a claim the value
never earned; it is now `version-malformed`. An envelope arriving in a dict
subclass or a null-prototype object — what `object_pairs_hook` and
pollution-safe JSON parsers actually hand back — used to be reported as
missing entirely, hiding every real finding; the checker now names the true
problem and the one-line fix.

One detail from the build is worth recording. The previous blind-validation
run caught an auditor printing a clean format verdict over a report the
checker fails, because its session was barred from writing the temp file the
self-check needs. This release rewrote the rule: the clean marker is earned
by an execution, and any obstacle is the `not run (<reason>)` case, reason
stated. The pre-tag harness for this release then watched the fix work under
the exact same constraint — the blocked auditor declared itself unvalidated,
the orchestrator's checker caught its defects, and one of those defects
turned out to be a hole in our own report contract: a fixture staged outside
any git repository has no legal `commit` value, so a truthful auditor had no
way to say so. That is now a tracked issue. The honesty machinery found a
flaw in the honesty machinery, which is the behavior it exists to have.

Also in this release: the adopt skill's routing report gains the contract its
siblings already had (`routing-format: v1`, checker-validated), bootstrap
actually installs the provenance lint it had only ever described, and
`portable/README.md` is a new entry point that hands the audit method to any
capable coding agent without the plugin shell — host-neutral by design today,
with the measured non-Claude run tracked and assigned rather than assumed.

Before the tag: six blind auditors re-validated the audit skill against the
planted-violation fixtures, 6/6 findings PASS, recorded in
[validation-results.md](../validation-results.md). The self-audit of the
release diff found six findings, zero violations; four fixed before the tag,
two deferred as tracked issues.
