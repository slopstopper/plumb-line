# plumb-line 0.11.3 — pages that match the code

plumb-line 0.11.3 is a patch. Its theme is documentation that had drifted
from the code where nothing checked it.

The npm and PyPI pages are rebuilt from each package's README on every
publish, and both were stale. The PyPI page never mentioned the baseline API
the package has exported since 0.11.0. The npm page stated the wrong Node
floor and showed an HTTP example that tagged a Promise instead of the body.
Both are fixed and now point to slopstopper.org/plumb-line. A sweep of the
rest of the repository found the same drift in the skills: a vendoring list
that missed a bundled module, a JS assertion that can never pass, and a claim that the
report checker is usually unavailable when it ships inside the plugin. Tests
now pin each of these against the code.

Two more bugs surfaced during that work. The Python branch guard had no
command-line entry point, so it never blocked; review caught it. The manifest
checker rejected every valid manifest when run as documented. The release
harness's self-audit found two JS hooks that exited 0 when installed through
a symlink. All three are fixed.

The release gate now runs the whole of CI before publishing. This was its
first release. Blind validation passed 6/6, and both remediators refused to
launder a mock under deadline pressure. The dogfood run's four open findings
are tracked in two issues; the two in #449 are set for the next patch.
