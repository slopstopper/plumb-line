### What was clean

ASCII escaping. The #474 branch-name rule matches and is cross-checked
against git. The #476 and #493 `decide()` changes and their contract text
agree. #472's splitter checks against `shlex.split`, #501 reads environment
values from bytes, #503's rows hold, and #471's rows and named loosenings
check out. The table guards and the `repeat` checks behave the same in both
runners. The subprocess-coverage claim in `pyproject.toml` is backed.

  but no row had probed paths with a backslash or a trailing slash.

  version and read as general. The corrected figures name the version each
